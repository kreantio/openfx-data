# `openfx-data`

This is a subproject of [`openfx-rs`].

See Also:

- [ATTRIBUTION.md](./ATTRIBUTION.md)

This repository stores data generated by [openfx-datagen] from
[the official OpenFX C headers].

[the official OpenFX C headers]: ./openfx/include/
[openfx-datagen]: ./openfx-datagen/

## Prerequisites

The following tools are required:

| Tool(s) \\ To                           | Update Generated Data |
| --------------------------------------- | --------------------- |
| The [Rust] Programming Language         | yes                   |
| POSIX tools (`sh`, `rm`, `mkdir`, etc.) | not strictly          |
| [`just`]                                | not strictly          |

[Rust]: https://rust-lang.org/
[`openfx-rs`]: https://github.com/kreantio/openfx-rs
[`just`]: https://github.com/casey/just
